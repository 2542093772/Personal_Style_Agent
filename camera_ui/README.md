# Camera Session

This module provides a local browser camera session for the Personal Style Agent.

Privacy principles:
- Camera is off by default.
- The browser must explicitly grant permission.
- The user must press Start Camera to begin.
- A visible indicator is shown while the camera is active.
- Press Stop Camera to immediately stop all MediaStream tracks.
- No background recording.
- Frames are only sent for analysis when the user explicitly enables analysis.
- Saving images is disabled by default.
