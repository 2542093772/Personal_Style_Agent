# Shopping Recommendation Layer

This module turns style advice into purchasable recommendations.

Principles:

1. Recommend only when a product fills a real wardrobe or styling need.
2. Prefer official / authorized / trustworthy sellers.
3. Keep product links and prices time-stamped because availability changes.
4. Popularity is weak evidence; personal fit is the strongest score.
5. Never let shopping data directly rewrite personal style rules.

Typical flow:

style need -> search products -> verify link/seller/price -> score personal fit -> shortlist -> user feedback -> purchase history
