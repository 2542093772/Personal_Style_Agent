# Continuous visual collection policy

Default purpose: improve the personal style profile, not continuously judge the user.

When the user explicitly enables continuous collection:

- Sample frames periodically while the camera session is active.
- Extract only styling-relevant visible characteristics.
- Aggregate repeated observations to reduce single-frame errors.
- Do not infer sensitive traits.
- Do not save raw camera images by default.
- Store derived profile observations and a stable aggregate profile only.
- Stop collection immediately when the user disables collection or stops the camera.
- Real-time outfit critique is a separate opt-in mode.
