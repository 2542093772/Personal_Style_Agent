# Orchestrator V1

The Orchestrator owns *when* daily agents run. GitHub Actions owns execution.

## Render environment

Configure:

- `ORCHESTRATOR_SECRET`: generated by Render Blueprint.
- `GITHUB_ORCHESTRATOR_TOKEN`: fine-grained GitHub PAT limited to this repository.
  Required repository permission: **Actions: Read and write**.
- Existing Telegram variables remain unchanged.

Do not commit secret values.

## Dispatch endpoints

Authenticated POST endpoints:

- `/orchestrator/dispatch/style/overnight_learning`
- `/orchestrator/dispatch/style/morning_brief`

Header:

`X-Orchestrator-Secret: <ORCHESTRATOR_SECRET>`

The endpoint calls GitHub workflow_dispatch on `style-learning.yml`.

## External clock

Configure a reliable external cron provider to call:

- 01:30 Asia/Shanghai -> `style/overnight_learning`
- 07:45 Asia/Shanghai -> `style/morning_brief`

If the provider schedules in UTC:

- 17:30 UTC previous day -> 01:30 Asia/Shanghai
- 23:45 UTC previous day -> 07:45 Asia/Shanghai

The external scheduler must send the secret header above.

## Health / registry

GET `/orchestrator/status` returns the registered agents/tasks without exposing secrets.

## Architecture

External Clock -> Render Orchestrator -> GitHub workflow_dispatch -> Agent job -> reports/state -> Telegram.

GitHub's daily cron entries are intentionally removed to prevent duplicate runs. Weekly/monthly maintenance remains on GitHub schedule for now.
